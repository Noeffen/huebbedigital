Spotify Sync

Startet denselben Song auf zwei Handys mit zwei verschiedenen Spotify-Accounts nahezu gleichzeitig. Beide Spotify-Apps müssen dafür auf den Zielhandys offen/im Hintergrund aktiv sein.

Einmalige Einrichtung:
Client ID von deiner App aus dem Spotify Developer Dashboard hier eintragen (Redirect URI dort muss exakt https://huebbedigital.com/spotify-sync.html sein).
